### What I care about

- **Design systems:** component APIs, design tokens, docs that stay true.
- **Motion with a reason:** timing and easing that make an interface feel right, plus `prefers-reduced-motion`.
- **Accessible UI:** keyboard, focus and states first, not as an afterthought.
- **Building with AI:** Cursor / Claude in the loop, with every line reviewed by hand.
